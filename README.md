# Codewars Solutions

This repository contains my solutions to Codewars kata. It is a personal practice space for improving problem-solving skills and working with different programming languages.

## Contents

The solutions are organized by language and Codewars difficulty level:

- **Python**: Kyu 5, Kyu 6, Kyu 7, and Kyu 8
- **JavaScript**: Kyu 7 and Kyu 8
- **TypeScript**: Kyu 5, Kyu 6, Kyu 7, and Kyu 8

Each language directory contains one file per kata. File names are based on the title of the corresponding Codewars challenge.

## Purpose

The repository is used to:

- Practice programming fundamentals and problem solving.
- Explore different ways to approach the same type of problem.
- Track progress through Codewars difficulty levels.
- Keep solutions available for future review and learning.

These solutions are part of my learning process, so they may vary in style and complexity as I continue improving.
